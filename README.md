Phoenix

Phoenix is a next-generation GPU computing and AI acceleration research project focused on CUDA, parallel computing, GPU architecture, and high-performance systems.

🎯 Goals
Explore GPU architecture and parallel computing
Develop high-performance CUDA kernels
Research GPU and AI acceleration techniques
Benchmark and optimize compute workloads
Explore future heterogeneous and accelerator architectures
🛠️ Technologies
C / C++
CUDA
NVIDIA GPU Architecture
CMake
Python
Linux / Windows
🚀 Status

Early-stage research and development.

The project is actively evolving as new experiments, benchmarks, and optimizations are developed.
